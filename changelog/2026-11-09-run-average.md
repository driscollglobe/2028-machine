The 2028 Machine, run odds from both books of 2026-11-09

Each candidate's chance of running now comes from the average of Kalshi's run market and Polymarket's "Who will announce Presidential run before 2028?" market, or from the one book that lists them. Before, only Kalshi counted. Khanna, Talarico and El-Sayed have no Polymarket run contract, so they keep Kalshi's price. markets.json now carries run_kalshi and run_polymarket beside run, the average.

Jon Ossoff's run odds were not coming from either market. They came from a slider added in July 2026, "Ossoff reverses his denial," set at 90 percent. Before Georgia was settled it was multiplied by his chance of winning it; once he won, 90 became his run odds outright, while his field card showed Kalshi's number. The slider is now "Ossoff runs" and is set from the run average every night, the way AOC's and Harris's already were. On 2026-11-09 that is 63.5 percent (Kalshi 68, Polymarket 59).

El-Sayed keeps his own rule (he runs only if AOC stays out, then 70 percent), and Fain keeps his cap of 15.
